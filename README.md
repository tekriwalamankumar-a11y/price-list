# Tekriwal Corporation — Website Packages

Static package and pricing proposal website. Open `index.html` to view the package overview.

## Pages and files

- `index.html` — package overview and links
- `package-whatsapp.html` — WhatsApp enquiry website package
- `package-store.html` — website with cart and checkout package
- `package-software.html` — website plus offline software package
- `styles.css` and `script.js` — shared presentation styling and interactions

This is a static site with no build step. Keep the HTML, CSS and JavaScript files together at the repository root so the relative links continue to work. The root `index.html` is the entry page for static hosting.
